# BookCatalog

Каталогизатор книг.

## Что уже реализовано

- импорт отдельных файлов книг и папок;
- отображение книг на книжной полке;
- извлечение метаданных и обложек из FB2;
- ручное добавление книги;
- редактирование основных данных книги;
- удаление книг из каталога;
- простой поиск по названию;
- обработка конфликтов метаданных при повторном импорте;
- хранение каталога в JSON;
- обработка отсутствующих или перемещённых файлов без падения программы.

## Запуск

## Структура проекта

main_gui.py - графический интерфейс и обработка действий пользователя
process_manager.py - управление основными сценариями и взаимодействием частей программы
book_manager.py - логика работы с книгами в каталоге
database.py - загрузка, сохранение и поиск данных в базе
file_operations.py - поиск и обработка файлов книг
metadata.py - извлечение метаданных и обложек из файлов книг
validation.py - проверка структуры и допустимости данных книги

## Планы
